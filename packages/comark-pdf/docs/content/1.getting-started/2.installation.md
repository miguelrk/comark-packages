---
title: Installation
description: Install comark-pdf with pnpm, npm, or yarn. comark is a required peer dependency.
navigation:
  icon: i-lucide-download
---

::code-group
```bash [pnpm]
pnpm add comark-pdf comark
```
```bash [npm]
npm install comark-pdf comark
```
```bash [yarn]
yarn add comark-pdf comark
```
::

`comark` is a peer dependency.

## Optional peers

Some features need extra packages at runtime:

| Package | Used for |
| --- | --- |
| `mathjax-full` | Math plugin — `$…$` / `$$…$$` as SVG instead of Courier source |
| `mermaid` | Mermaid fences as SVG (may need DOM / `happy-dom`) |
| `@jasy/pdf` | Direct jasy primitives in custom components |

See [Plugins](/guide/plugins) and [Custom components](/guide/custom-components).
