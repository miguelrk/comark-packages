**comark-pdf** is the PDF renderer for [Comark](https://comark.dev). It converts Comark Markdown to print-ready PDF bytes through [jasy](https://jasy.dev) — no headless browser required.

## How it works

Three layers, one job each:

| Layer | Job |
| --- | --- |
| [Comark](https://comark.dev) | Parse markdown to an AST. |
| `comark-pdf` | Read that AST. Choose policy. Call jasy primitives. |
| [jasy](https://jasy.dev/docs/pdf) | Draw and lay out PDF primitives. It does not parse Markdown, Mermaid, KaTeX, or Shiki. |

Merge order for page config (last write wins): `frontmatter.pdf` → `options.pdf`.

## What you get

- **One-shot or reusable renderers** — `renderPdf()` or `createPdfRenderer()` with a parser initialized once
- **Node helpers** — `renderPdfToBuffer` and `renderPdfToFile` from `comark-pdf/node`
- **Browser preview** — mount bytes with `comark-pdf/preview`
- **Host options** — page size, margins, chrome, fonts, visuals, plugins, components, and binding data
- **Feature matrix** — see [Syntax matrix](/reference/syntax-matrix) for what Comark syntax maps to PDF

::note
`comark` is a peer dependency. Install it in your app alongside `comark-pdf`.
::
