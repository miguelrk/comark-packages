Use `isSingleDriverSchema` to narrow `tree.meta.kv` at runtime.

## Narrow the schema type

```ts [narrow.ts]
import { isSingleDriverSchema } from 'comark-kv'

if (isSingleDriverSchema(tree.meta.kv!)) {
  // KvDescriptor — paths kv.key
} else {
  // KvNamespaceMap — paths kv.ns.key
}
```

Import from `comark-kv` or `comark-kv/model` depending on your bundle. The helper is the same function.
