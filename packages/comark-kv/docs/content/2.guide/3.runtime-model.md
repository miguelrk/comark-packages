`createKvModel` builds a writable model from `tree.meta.kv`. It works without Vue.

## Create a model handle

```ts [create-model.ts]
import { createKvModel } from 'comark-kv/model'

const { model, ready, dispose, storages } = await createKvModel(tree.meta.kv!)
await ready
```

## Read and write paths

```ts [get-set.ts]
// Single-driver
model.get('kv.name')
model.set('kv.name', 'Bob')

// Multi-driver
model.get('kv.config.name')
model.set('kv.config.name', 'Bob')

// HTTP URL shortcut (resource namespace)
model.get('kv.todos')           // remote JSON
model.get('kv.todos.0.title')   // nested path into the resource
```

## Access raw storages

```ts [storages.ts]
storages['config'].getItem('user-config:name')
```

Use individual storages for advanced use, debugging or tests.

## Dispose when done

```ts [dispose.ts]
dispose()
```

Call `dispose()` to tear down watchers and release storage handles.
