**comark-kv** is a [Comark](https://comark.dev) plugin. It declares a `kv:` block in frontmatter, backed by [unstorage](https://unstorage.unjs.io), and exposes a live writable `kv.*` namespace for two-way `::prop` model binding.

## Two forms

| Form | Frontmatter | Model paths |
|---|---|---|
| **Single-driver** | `kv: { driver, mount, default }` | `kv.key` |
| **Multi-driver** | `kv: { ns: { driver, mount, default } }` | `kv.ns.key` |

## What it does

- **Parses `kv:` frontmatter** at parse time into a descriptor on `tree.meta.kv`
- **Creates unstorage backends** for each driver or namespace
- **Exposes a runtime model** with `get` and `set` on dotted `kv.*` paths
- **Syncs with the UI** through two-way `::prop` bindings on inputs and forms

## Peer dependencies

`comark` is a peer dependency. `vue` is an optional peer for the `comark-kv/vue` composable.
