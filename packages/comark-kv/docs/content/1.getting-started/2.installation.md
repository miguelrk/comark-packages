---
title: Installation
description: Install comark-kv and unstorage with pnpm, npm, or yarn. comark is a peer dependency.
navigation:
  icon: i-lucide-download
---

::code-group
```bash [pnpm]
pnpm add comark-kv unstorage
```
```bash [npm]
npm install comark-kv unstorage
```
```bash [yarn]
yarn add comark-kv unstorage
```
::

`comark` is a peer dependency. `vue` is an optional peer for the `comark-kv/vue` composable.

## Add comark

::code-group
```bash [pnpm]
pnpm add comark
```
```bash [npm]
npm install comark
```
```bash [yarn]
yarn add comark
```
::

## Add Vue (optional)

::code-group
```bash [pnpm]
pnpm add vue
```
```bash [npm]
npm install vue
```
```bash [yarn]
yarn add vue
```
::
