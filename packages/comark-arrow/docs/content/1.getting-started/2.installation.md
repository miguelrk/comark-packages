## Core plugin

::code-group
```bash [pnpm]
pnpm add comark-arrow @arrow-js/sandbox
```
```bash [npm]
npm install comark-arrow @arrow-js/sandbox
```
```bash [yarn]
yarn add comark-arrow @arrow-js/sandbox
```
::

`comark` is a peer dependency. `@arrow-js/sandbox` is required for the Vue renderer (optional if you only parse).

## Vue renderer

For interactive widgets in the browser:

::code-group
```bash [pnpm]
pnpm add vue @comark/vue
```
```bash [npm]
npm install vue @comark/vue
```
```bash [yarn]
yarn add vue @comark/vue
```
::

::note
Pin `@arrow-js/sandbox` to `1.0.6` (Early Access). Re-check the API when you upgrade.
::
