Control the generated node type with the `output=` attr or a [frontmatter](/guide/frontmatter) default.

## Use inline SVG (default)

| Mode | Generated node | Notes |
| --- | --- | --- |
| `svg` (default) | inline `<svg>` | Supports CSS `currentColor` theming |

```md [svg.md]
::qrcode{value="https://example.com" output="svg"}
::
```

## Emit an img with SVG data URI

| Mode | Generated node | Notes |
| --- | --- | --- |
| `img` | `<img src="data:image/svg+xml;…">` | Portable single element |

```md [img.md]
::barcode{value="4006381333931" type="ean13" output="img"}
::
```

## Emit PNG as a data URI

| Mode | Generated node | Notes |
| --- | --- | --- |
| `png` | `<img src="data:image/png;base64,…">` | Not available for `jabcode` |

```md [png.md]
::qrcode{value="https://example.com" output="png"}
::
```

## Set a document-wide default

```yaml [frontmatter.md]
---
etiket:
  output: svg
---
```

Per-directive attrs always override frontmatter and plugin defaults.
