Set global defaults in the document frontmatter under the `etiket` key. Per-directive attrs always take precedence.

## Set global defaults

```markdown [defaults.md]
---
etiket:
  output: svg
  ecLevel: H
  color: currentColor
  qrcode:           # per-tag overrides
    dotType: rounded
---

::qrcode{value="https://example.com"}
::
```

## Override per symbology

Nest a tag name under `etiket` to override defaults for that directive only:

```yaml [per-tag.md]
etiket:
  output: svg
  barcode:
    showText: true
  qrcode:
    dotType: dots
    ecLevel: H
```

## Layer plugin factory defaults

Pass defaults via the plugin factory — frontmatter values override these. See [Plugin options](/reference/plugin-options).

Precedence (lowest to highest):

1. Plugin factory `etiket({ etiket: { … } })`
2. Document frontmatter `etiket:`
3. Per-directive attrs
