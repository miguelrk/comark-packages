Batch sheet directives render multiple codes from child lines or a JSON `values=` array.

## Render a barcode sheet from child lines

```md [barcode-sheet.md]
::barcode-sheet{type="ean13"}
4006381333931
9780141036144
::
```

## Render a QR sheet from child lines

```md [qr-sheet.md]
::qr-sheet
https://comark.dev
https://example.com
::
```

## Pass values as a JSON array

```md [barcode-sheet-json.md]
::barcode-sheet{type="code128" values='["SKU-001","SKU-002","SKU-003"]'}
::
```

Each value becomes one encoded symbol in the sheet layout etiket produces.
