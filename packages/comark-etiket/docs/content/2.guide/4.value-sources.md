Every symbology directive needs a payload. comark-etiket resolves it from three sources, in order of precedence for the directive syntax you use.

## Set the value attribute

```md [value-attr.md]
::qrcode{value="https://example.com"}
::
```

## Use inline content

```md [inline.md]
:qrcode[https://example.com]
```

## Put text in the block body

```md [block-body.md]
::qrcode
https://example.com
::
```

## Bind a runtime value

`:value="user.profileUrl"` cannot be resolved at parse time. Those nodes stay in the AST for your renderer. See [Binding behaviour](/guide/binding).
