Pass defaults via the plugin factory — [frontmatter](/guide/frontmatter) values override these.

## Configure plugin defaults

```ts [plugin.ts]
import etiket from 'comark-etiket'

const plugins = [
  etiket({
    etiket: {
      output: 'svg',
      ecLevel: 'H',
    },
  }),
]
```

## Pass per-tag overrides

Nest a tag name under `etiket` in the factory options, same shape as frontmatter:

```ts [per-tag.ts]
etiket({
  etiket: {
    output: 'svg',
    qrcode: {
      dotType: 'rounded',
      ecLevel: 'H',
    },
    barcode: {
      showText: true,
    },
  },
})
```

## Set precedence

| Layer | Overrides |
| --- | --- |
| Plugin factory | Base defaults |
| Frontmatter `etiket:` | Factory defaults |
| Directive attrs | Frontmatter and factory |
