## Install the package

::code-group
```bash [pnpm]
pnpm add comark-etiket etiket
```

```bash [npm]
npm install comark-etiket etiket
```

```bash [yarn]
yarn add comark-etiket etiket
```
::

`comark` and `etiket` are peer dependencies. Your app already uses `comark` for parsing; etiket provides the encoders.

## Optional peers

No extra packages are required for parse-time SVG output. For PNG output (`output="png"`), etiket handles encoding internally.

If you use `@comark/vue`, add it alongside your existing Comark setup:

```bash [pnpm]
pnpm add @comark/vue
```
