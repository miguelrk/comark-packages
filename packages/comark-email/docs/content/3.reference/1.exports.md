## `comark-email`

| Export | |
|---|---|
| `createEmailRenderer` | factory with shared `options.email` defaults |
| `renderEmail` | render markdown string to `{ html, text, subject, previewText }` |
| `renderEmailFromDocument` | render a pre-parsed Comark document |
| `documentToMjml` | Comark document → MJML string |
| `documentToText` | plain-text fallback from document |
| `compileMjml` | MJML string → HTML |
| types | TypeScript types for options and results |

## `comark-email/render`

| Export | |
|---|---|
| `renderEmailFromDocument` | render from parsed document |
| `documentToMjml` | document → MJML |
| `documentToText` | plain-text fallback |
| `compileMjml` | MJML → HTML |
| `documentToMjmlJson` | document → MJML JSON tree |
| `serializeMjml` | MJML JSON → string |

## `comark-email/config`

| Export | |
|---|---|
| `resolveEmailConfig` | merge frontmatter and options into email config |
| `buildMjmlHead` | build MJML `<mj-head>` from resolved config |
