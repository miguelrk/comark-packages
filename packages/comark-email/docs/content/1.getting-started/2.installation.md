---
title: Installation
description: Install comark-email with pnpm, npm, or yarn, plus peer dependencies comark and @comark/html.
navigation:
  icon: i-lucide-download
---

::code-group
```bash [pnpm]
pnpm add comark-email
```
```bash [npm]
npm install comark-email
```
```bash [yarn]
yarn add comark-email
```
::

`comark` and `@comark/html` are peer dependencies. `mjml` is a dependency.

## Verify peers

Your app also needs `comark` and `@comark/html` for parsing and HTML fallbacks:

::code-group
```bash [pnpm]
pnpm add comark @comark/html
```
```bash [npm]
npm install comark @comark/html
```
```bash [yarn]
yarn add comark @comark/html
```
::
