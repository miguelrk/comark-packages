Email settings live under `email:` in frontmatter. Top-level aliases also merge in.

## Set email metadata

```yaml [frontmatter]
---
email:
  subject: "Your order has shipped!"
  previewText: "Track your package delivery status."
  brandColor: "#0066cc"
  theme:
    background: "#f4f5f7"
---
```

## Understand merge order

Merge order (last write wins):

1. Top-level frontmatter aliases
2. `frontmatter.email`
3. `options.email` passed to `renderEmail` or `createEmailRenderer`

Use frontmatter for per-template values. Use renderer options for shared brand defaults across many templates.
