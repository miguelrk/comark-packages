Email layout components map to native MJML tags. Pass MJML attributes directly on each component.

## Add a button

```markdown [button.md]
::email-button{href="https://example.com" background-color="#0066cc" color="#ffffff" border-radius="4px"}
Click Here
::
```

Maps to `mj-button`.

## Build a multi-column layout

```markdown [columns.md]
::email-columns
Left column content.

Right column content.
::
```

Maps to `mj-section` + `mj-column`.

## Insert a divider

```markdown [divider.md]
::email-divider{border-color="#cccccc"}
::
```

Maps to `mj-divider`.

## Use MJML attributes

All three components accept MJML attributes as component props — `background-color`, `padding`, `align`, `font-size`, and others supported by the underlying MJML tag.
