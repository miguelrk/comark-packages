navigation:
  icon: i-lucide-download
---

::code-group
```bash [pnpm]
pnpm add comark-vega comark vega vega-lite
```
```bash [npm]
npm install comark-vega comark vega vega-lite
```
```bash [yarn]
yarn add comark-vega comark vega vega-lite
```
::

`comark`, `vega`, and `vega-lite` are peer dependencies.

## Vue renderer

For the shipped Vue component:

::code-group
```bash [pnpm]
pnpm add vue @comark/vue
```
```bash [npm]
npm install vue @comark/vue
```
```bash [yarn]
yarn add vue @comark/vue
```
::

`vue` is an optional peer for `comark-vega/vue`.

## PNG output

`output="png"` requires the `canvas` peer dependency.

See [Output modes](/guide/output-modes).
