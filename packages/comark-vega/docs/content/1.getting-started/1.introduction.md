**comark-vega** is a [Comark](https://comark.dev) plugin for [Vega](https://vega.github.io/vega/) and [Vega-Lite](https://vega.github.io/vega-lite/). It turns fenced blocks and directives into chart nodes in the AST.

## Two rendering paths

| Path | When |
| --- | --- |
| **Plugin + Vue renderer** | Interactive apps — recommended. Mount charts at runtime with the shipped `<Vega>` component. |
| **Parse-time SVG** | Static docs — opt in with `::vl`, `::vg`, `::chart`, or mark shortcuts. |

Parse-time SVG is **opt-in**. The default plugin path produces `['Vega', VegaNodeAttrs]` component nodes for your renderer.

## Shared AST shape

Both [entry points](/guide/entry-points) produce identical `['Vega', VegaNodeAttrs]` nodes. Map them with the shipped Vue component or a custom renderer via `mountVegaView`.

## Credits

Chart rendering is provided by [vega](https://github.com/vega/vega) and [vega-lite](https://github.com/vega/vega-lite), maintained by the [Vega team](https://github.com/vega). This plugin wraps those libraries for Comark; it does not reimplement compilation or rendering.

::note
`comark`, `vega`, and `vega-lite` are peer dependencies. `vue` and `@comark/vue` are optional peers for `comark-vega/vue`.
::
