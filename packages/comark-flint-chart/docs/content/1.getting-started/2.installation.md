## Install the package

::code-group
```bash [pnpm]
pnpm add comark-flint-chart flint-chart
```

```bash [npm]
npm install comark-flint-chart flint-chart
```

```bash [yarn]
yarn add comark-flint-chart flint-chart
```
::

`comark` and `flint-chart` are peer dependencies.

## Add the Vue renderer

For the Vue renderer:

::code-group
```bash [pnpm]
pnpm add vue @comark/vue vega-embed vega vega-lite
# optional ECharts backend:
pnpm add echarts
```

```bash [npm]
npm install vue @comark/vue vega-embed vega vega-lite
# optional ECharts backend:
npm install echarts
```

```bash [yarn]
yarn add vue @comark/vue vega-embed vega vega-lite
# optional ECharts backend:
yarn add echarts
```
::

Parse-time `svg` / `img` output is **opt-in** (`output: 'svg'` or `output: 'img'`). Default `output: 'component'` needs the client `<Flint>` renderer.

For static SVG/img without Vue, install `vega` + `vega-lite` (and/or `echarts`) as peers.
