**comark-flint-chart** is a [Comark](https://comark.dev) plugin for [Flint](https://github.com/microsoft/flint-chart) charts. It compiles Flint specs into backend-native charts and emits a `<Flint>` component node.

Ships a Vue renderer; parse-time SVG/img is an **opt-in** for static docs.

## What it does

- Parses fenced ` ```flint ` code blocks and `::flint` directives
- Assembles a [`ChartAssemblyInput`](https://github.com/microsoft/flint-chart) JSON spec via Flint
- Writes a `<Flint>` AST node with compiled spec, backend, and theme
- Optionally emits inline SVG or img at parse time when `output: 'svg'` or `output: 'img'`

## When to use it

Use **comark-flint-chart** when you need charts inside Comark markdown:

- Interactive apps with the shipped Vue `<Flint>` renderer (recommended)
- Static docs or PDF with opt-in `output: 'svg'`
- Dashboards that bind `:spec="path.to.chart"` from frontmatter

## What it is not

- Not a reimplementation of Flint assemblers — compilation is provided by [flint-chart](https://github.com/microsoft/flint-chart)
- Not a standalone chart library — you need backend peers (`vega`, `vega-lite`, `echarts`, …) for rendering

See [ChartAssemblyInput](/reference/chart-assembly-input) for the spec schema.
