comark-etiket barcodes and QR codes. Full plugin docs live at [comark-etiket](https://miguelrk.github.io/comark-packages/comark-etiket/).

```ts
import etiket from 'comark-codemirror/plugins/etiket'

comark({ plugins: [etiket()] })
```

## What it adds

- **Components**: `::qrcode`, `::microqr`, `::rmqr`, `::barcode`, `::postal`, `::datamatrix`, `::gs1datamatrix`, `::pdf417`, `::micropdf417`, `::aztec`, `::maxicode`, `::dotcode`, … (29)
