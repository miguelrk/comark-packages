comark-email layout components.

```ts
import email from 'comark-codemirror/plugins/email'

comark({ plugins: [email()] })
```

## What it adds

- **Components**: `::email-button`, `::email-divider`, `::email-columns`

## Components

| Component | Props | Slots |
|---|---|---|
| `::email-button` | `href`, `background-color`, `color`, `align` (left \| center \| right), `border-radius`, `font-size`, `width`, `target`, `padding` | – |
| `::email-divider` | `border-color`, `border-width`, `padding` | – |
| `::email-columns` | `background-color`, `padding` | – |

## For agents

Included in `llms()`:

> Email components (comark-email): `::email-button{href="…"}`, `::email-divider`, `::email-columns`.
