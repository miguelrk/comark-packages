comark-pdf page breaks.

```ts
import pageBreak from 'comark-codemirror/plugins/page-break'

comark({ plugins: [pageBreak()] })
```

## What it adds

- **Components**: `::page-break`

## Components

| Component | Props | Slots |
|---|---|---|
| `::page-break` | `type` (after \| before) | – |

## For agents

Included in `llms()`:

> Page breaks for PDF output (comark-pdf): `::page-break` and `::` on their own lines.
