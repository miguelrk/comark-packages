YAML frontmatter: keys and values from `frontmatterSchema`, required keys and enum values checked.

```ts
// registered by default; to configure it:
import frontmatter from 'comark-codemirror/plugins/frontmatter'

comark({ plugins: [frontmatter()] })
```

## What it adds

- **Completion** in `block`, `frontmatter-key`, `frontmatter-value`
- **Lint**

## For agents

Included in `llms()`:

> Frontmatter: YAML between `---` lines at the very top of the document. Its values are available to bindings as `frontmatter.*`.
