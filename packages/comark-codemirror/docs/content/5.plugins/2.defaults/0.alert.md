GitHub-style `> [!TYPE]` callouts.

```ts
// registered by default; to configure it:
import alert from 'comark-codemirror/plugins/alert'

comark({ plugins: [alert()] })
```

## What it adds

- **Completion** in `alert`
- **Snippets**: *Note*, *Tip*, *Important*, *Warning*, *Caution*

## For agents

Included in `llms()`:

> Alerts: a blockquote whose first line is `[!TYPE]` with TYPE one of NOTE, TIP, IMPORTANT, WARNING, CAUTION.
>
> ```md
> > [!TIP]
> > Helpful advice.
> ```
