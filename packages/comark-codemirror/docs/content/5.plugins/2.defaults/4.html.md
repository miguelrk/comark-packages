HTML tags and attributes, and the closing tag of the open element.

```ts
// registered by default; to configure it:
import html from 'comark-codemirror/plugins/html'

comark({ plugins: [html()] })
```

## What it adds

- **Completion** in `html-tag`, `html-attr`
- **Snippets**: *Details*

## For agents

Included in `llms()`:

> HTML blocks and inline HTML are allowed (`<div>`, `<br>`, `<details>`). Prefer components over raw HTML.
