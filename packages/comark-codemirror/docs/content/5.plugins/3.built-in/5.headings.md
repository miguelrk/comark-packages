Heading anchors, duplicate and broken anchor checks, `meta.title` and `meta.description`.

```ts
import headings from 'comark-codemirror/plugins/headings'

comark({ plugins: [headings()] })
```

## What it adds

- **Completion** in `link-url`
- **Binding roots** (`scopes`)
- **Lint**

## For agents

Included in `llms()`:

> Headings get ids automatically (`## Install` → `#install`; h3+ ids are prefixed by their parent heading). Link with `[text](#id)`; set an id with `## Title {#custom}`.
