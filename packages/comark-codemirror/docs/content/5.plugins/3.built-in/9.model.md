Two-way `::prop="data.x"` bindings.

```ts
import model from 'comark-codemirror/plugins/model'

comark({ plugins: [model()] })
```

## For agents

Included in `llms()`:

> Two-way binding: `::value="data.name"` on inputs and components writes back to `data`. Example: `:input{::value="data.email" type="email"}`.
