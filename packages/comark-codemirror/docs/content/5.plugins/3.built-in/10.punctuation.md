Typographic quotes, dashes and ellipses.

```ts
import punctuation from 'comark-codemirror/plugins/punctuation'

comark({ plugins: [punctuation()] })
```

## What it adds

- **Commands**: `applyPunctuation`

## For agents

Included in `llms()`:

> Straight quotes, `--`, `---` and `...` render as typographic characters; plain ASCII is fine.
