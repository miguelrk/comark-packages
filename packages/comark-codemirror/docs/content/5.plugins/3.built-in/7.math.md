Inline and display LaTeX, with KaTeX commands.

```ts
import math from 'comark-codemirror/plugins/math'

comark({ plugins: [math()] })
```

## What it adds

- **Completion** in `math`
- **Snippets**: *Math block*, *math*
- **Fence languages**: `math`, `latex`

## For agents

Included in `llms()`:

> Math: inline `$x^2$`, display `$$` on their own lines around LaTeX (KaTeX).
