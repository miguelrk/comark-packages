Footnote references and definitions.

```ts
import footnotes from 'comark-codemirror/plugins/footnotes'

comark({ plugins: [footnotes()] })
```

## What it adds

- **Completion** in `footnote`
- **Snippets**: *Footnote*
- **Lint**
- **Commands**: `insertFootnote`

## For agents

Included in `llms()`:

> Footnotes: reference with `[^1]`, define on its own line with `[^1]: text`.
