`{{ path || fallback }}` interpolation and the `::if` / `::for` components.

```ts
import binding from 'comark-codemirror/plugins/binding'

comark({ plugins: [binding()] })
```

## What it adds

- **Completion** in `binding-path`, `binding-default`
- **Snippets**: *binding*
- **Components**: `::if`, `::for`

## Components

| Component | Props | Slots |
|---|---|---|
| `::if` | `value`, `eq`, `neq`, `gt`, `gte`, `lt`, `lte`, `as` (div \| span \| p \| section \| article \| aside \| header \| footer \| main \| nav) | `#else` |
| `::for` | `each`, `item`, `index`, `key` | `#empty` |

## For agents

Included in `llms()`:

> Bindings: `{{ path }}` or `{{ path || fallback }}` inserts a value. Roots: `frontmatter.*` (this document), `props.*` (the enclosing component), `data.*`, `meta.*`. `::if{:value="path"}` … `#else` … `::` and `::for{:each="data.items" item="item"}` … `::` control rendering.
