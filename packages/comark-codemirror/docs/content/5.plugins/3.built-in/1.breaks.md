Soft line breaks render as `<br>`.

```ts
import breaks from 'comark-codemirror/plugins/breaks'

comark({ plugins: [breaks()] })
```

## For agents

Included in `llms()`:

> Line breaks inside a paragraph are kept as `<br>` (no trailing spaces needed).
