Fence languages rangi highlights (optional peer `rangi`).

```ts
import rangi from 'comark-codemirror/plugins/rangi'

comark({ plugins: [rangi()] })
```

## What it adds

- **Completion** in `fence-lang`

## For agents

Included in `llms()`:

> Fenced code is syntax highlighted by language with rangi.
