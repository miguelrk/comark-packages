Put the cursor in the editor below and try the triggers. The [playground](/play) has a clickable tour of every context and a live preview.

:editor-demo{demo="components" height="260px"}

| Type | You get |
|---|---|
| `/` on an empty line | the block menu: components, headings, lists, table, callouts, code, math, diagrams, snippets |
| `::` | block components (with a closer entry when a component is open) |
| `{` after a component | its props; required first, set ones hidden |
| `="` | the prop's values |
| `:` inside `{}` | props you can bind, then binding roots |
| `{{` | `frontmatter`, `props`, `data`, `meta` and loop variables, then their keys |
| `#` in a component | its slots |
| `---` under an opener | a YAML props block with the same props |
| `:` in text | inline components, and emoji after two letters |
| ```` ``` ```` | fence languages, then `[file]`, `{1,3-5}`, `diff`, `twoslash` |
| `> [!` | alert types |
| `[^` | footnotes, or a new one |
| `](#` | heading ids |
| `$\` | KaTeX commands |
| `<` | HTML tags |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd> | the menu for wherever you are; mid-line, the inline menu (marks, link, span, binding, math) |

Plain prose never opens a menu.
