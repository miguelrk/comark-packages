```ts
interface ComarkOptions {
  plugins?: EditorPlugin[]              // later ones replace same-name earlier ones
  registerDefaultPlugins?: boolean      // alert, attributes, components, frontmatter, html, task-list (default true)
  components?: ComponentDef[]           // the component manifest
  frontmatterSchema?: JSONSchema        // keys and values inside the frontmatter
  data?: unknown                        // the `data` binding root: a sample value…
  dataSchema?: JSONSchema               // …or a schema
  meta?: unknown
  metaSchema?: JSONSchema
  links?: LinkTarget[] | ((typed: string) => LinkTarget[] | Promise<LinkTarget[]>)  // pages and assets
  codeLanguages?: LanguageDescription[] // fenced code highlighting and fence-language completion
  completion?: {
    slash?: boolean                     // `/` opens the block menu (true)
    chain?: boolean                     // reopen after a pick with a next step (true)
    drill?: boolean                     // → and ← (true)
    info?: 'auto' | false               // docs panel ('auto')
    maxItems?: number                   // rendered options (80)
    icons?: boolean                     // (true)
  }
  lint?: boolean                        // (true)
  hover?: boolean                       // (true)
  keymap?: boolean                      // (true)
  theme?: boolean                       // (true)
}

interface LinkTarget { url: string, title?: string, kind?: 'page' | 'asset' }
```

## Keymap

| Key | Command |
|---|---|
| <kbd>Mod</kbd>+<kbd>B</kbd> / <kbd>I</kbd> | bold / italic |
| <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> / <kbd>X</kbd> | code / strikethrough |
| <kbd>Mod</kbd>+<kbd>K</kbd> | link |
| <kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>0</kbd>–<kbd>6</kbd> | heading level (0: paragraph) |
| <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>U</kbd> / <kbd>O</kbd> / <kbd>T</kbd> | bullet / ordered / task list |
| <kbd>Mod</kbd>+<kbd>Enter</kbd> | check or uncheck a task |
| <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>Q</kbd> | quote |
| <kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> | align the table |
| <kbd>Enter</kbd> at the end of `::name…` | body line and closer |
| <kbd>*</kbd> <kbd>_</kbd> <kbd>`</kbd> <kbd>~</kbd> over a selection | wrap it |

Plus the [menu keys](/autocomplete/chaining#keys).
